AutoLang · menu-bar identity

Five brand marks, each showing the live language

The idea: pair A (Latin) with א (Hebrew aleph), the first letter of each alphabet. Every mark renders monochrome so it adapts to a light or dark menu bar, and shows which language is currently active. Pick one from Icon style in the menu — styles switch live.
